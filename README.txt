БЫСТРЫЙ СТАРТ:

1. Установи Termux из F-Droid (не Play Store!)
   https://f-droid.org/packages/com.termux/

2. Скопируй эту папку в Termux:
   termux-setup-storage (разрешить доступ к файлам)
   cp -r /sdcard/Download/genesis_engine ~/

3. Запусти установщик:
   cd ~/genesis_engine
   bash setup.sh

4. Создай бота через @BotFather в Telegram
   Узнай свой ID через @userinfobot

5. Заполни конфиг:
   cp .env.example .env
   nano .env

6. Запусти:
   bash start.sh
